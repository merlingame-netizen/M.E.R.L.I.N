🜨 MERLIN — Voix du Conteur (test navigateur)

Zéro installation : utilise les voix de Windows / du navigateur (Web Speech API). Pour la même voix dans toutes les langues, choisis une voix marquée Multilingual (ou « Natural »). Le grave = baisse la hauteur (pitch).

Astuce : si aucune voix française grave n'est listée, ajoute-en une dans Windows → Paramètres → Heure et langue → Voix (voix « Natural/Multilingual » de Microsoft), puis recharge cette page. Pour la voix in-game (Godot), c'est le service Python (XTTS/edge) — mais pour écouter/valider le rendu ici, le navigateur suffit.
