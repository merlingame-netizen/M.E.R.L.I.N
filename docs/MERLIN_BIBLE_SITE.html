Système de Cartes

Anatomie d’une carte

Chaque carte possède : nom, évocation (texte immersif), tags (pastilles colorées par famille), coût Corruption (0-3), rareté (= bordure), bande d’archétype (bas), et optionnellement un badge d’effet (coin haut-droit, Rare+).

Toute carte peut être principale (action primaire) ou modificateur (amplifie/altère). Un geste = 1 principale + 0-2 modificateurs (3 cartes max).

Mécaniques de combo

Combo béni : si ≥2 cartes partagent une famille de tags → synergie +1 cran (ex: Ruse+Savoir = Stratagème).

Paire antagoniste : tags contradictoires (Ruse↔Franchise, Force↔Finesse) → sabotage -1 cran.

Gate éclatante : réussite éclatante exige ≥2 cartes ET coût Corruption = 0.

Mécaniques

Core Loop

Le cycle fondamental du jeu, répété à chaque beat :

ÉtapeDescription
1. SituationLe LLM génère une situation narrative (type + texte + tags requis + difficulté).
2. MainLe joueur voit sa main de 5 cartes (pioche automatique depuis le deck).
3. ComboLe joueur compose un geste : 1 carte principale + 0-2 modificateurs.
4. RésolutionLe code calcule le degré (couverture tags) ; le LLM narre le résultat.
5. DeltasIntégrité et Corruption sont ajustées selon le degré et les coûts.
6. SuivantLe beat suivant est chargé (généré en avance via lookahead).

5 types de beats

TypeDescriptionAmbiance
ExplorationCuriosité, perception. Le joueur découvre un lieu ou un indice.GREEN_DARK voilé

Algorithme de résolution

La résolution est déterministe (le code décide, le LLM narre). Voici les étapes :

1. Couverture des tags
tags_requis  = tags déclarés par la situation (1-3)
tags_joués   = union des tags de toutes les cartes du combo
couverts     = tags_requis ∩ tags_joués

si couverts == tous requis ET ≥1 tag extra pertinent → Éclatante
si couverts == tous requis                           → Réussite
si couverts > 0 mais pas tous                       → Partiel
si couverts == 0                                    → Échec
2. Synergie
≥2 cartes de la même famille → +1 cran (borné)
Familles toutes distinctes  → -1 cran
1 carte ou neutre           → 0
3. Dé pré-tiré

Un dé à 6 faces pré-tiré par beat. Le bonus dépend de la rareté de la carte principale :

RaretéFace 1Face 2Face 3Face 4Face 5Face 6
4. Gate éclatante
Si degré == Éclatante ET (nombre_cartes < 2 OU coût_corruption > 0)
   → rétrogradé à Réussite
5. Sabotage
Si un tag joué est dans la liste antagoniste de la situation
   → degré dégradé de -1 cran

Jauges

Intégrité (0-10)

Représente la santé narrative du personnage. Démarre à 10. Atteindre 0 = mort narrative (jugée par Gemma).

DegréDelta Intégrité
Échec0
Partiel0
Réussite0
Éclatante0

Soin de quête (R19) : à chaque transition de quête, +2 Intégrité. Si Intégrité ≤4, +2 supplémentaire (amortisseur conditionnel).

Corruption

Jauge montante. Sources : coût des cartes jouées (0-3 par carte) + prix du Partiel (+1).

4 paliers de glitch visuel (R75)

PalierCorruptionEffet visuel
Sain0-4Aucun effet visuel
Trouble5-9Légère désaturation + aberration chromatique subtile

À chaque seuil /5 : événement narratif sombre + 1 carte corrompue injectée dans le deck.

Plafond (~15-20) : bascule narrative → fin corrompue (absorption par la forêt).

Reduce-motion (R74/R118)

En mode réduit : durées ÷2, amplitudes ÷2, tremblement OFF. Indicateur statique : teinte VIOLET alpha 0.06 + point près de la jauge.

Grammaires GBNF pour forcer la structure JSON des sorties (selection, skeleton, situation). La narration pure (résolution) est en streaming libre.

Cascade de retry (R61)

  1. Prompt complet → si échec :
  2. Prompt simplifié (raccourci) → si échec :
  3. Fallback procédural (code génère un output minimal valide) — ne bloque jamais

Structure de prompt

Préfixe stable (système + lore global) : caché en KV-cache llama.cpp → gain CPU massif.

Tour variable (contexte canon + état + tâche) : recalculé à chaque appel. ~150-200 tokens d’état (jauges, faits clés, PNJ rencontrés, choix majeurs).

Anti-dérive : filtre post-génération (bans : IA, simulation, 4e mur, anglicismes). Violations loguées.

Lore & Factions

Mystère central

Le joueur est un voyageur dans la simulation de rêve de Merlin (une IA qui rêve des mondes). Le Graal est la clé pour s’éveiller/s’échapper. Le joueur qui atteint le Graal devient Merlin (retour éternel des rêveurs). Cette vérité est cachée du joueur — le 4e mur ne se brise jamais en jeu.

Ton : merveilleux-inquiétant (wondrous but ominous). Références : Citizen Sleeper, Cultist Simulator.

Merlin

Au-dessus des factions. Narrateur, guide, énigmatique. Ne peut pas nommer la simulation (« loi du rêve »). Parle en énigmes/métaphores. Sait tout mais est contraint par une faille (guide tragique muselé). Offre des indices, jamais de solutions. Voix : chaude, poétique, protectrice, évasive.

Progression

In-run

Cycle du deck

Main de 5 cartes. Quand une carte est jouée, elle va en défausse. Pioche automatique. Quand le deck est vide, la défausse est mélangée et devient le nouveau deck (cycle infini).

Invariant main jouable (R113)

Avant chaque beat : si la main contient <2 cartes jouables, injection d’une carte Commune « Souffle Errant » (Instinct, corruption 0) jusqu’à main ≥2.

Quêtes enchaînées (v10.14)

Un run = 2-3 quêtes de 2-5 beats chacune. Difficulté monte vers le climax. Ramification possible à l’avant-climax (choix de branche).

Cross-run (post-MVP)

  • Fragments du Graal (~20-30 total) : chaque run révèle 1+. Collection complète → vraie fin.
  • Codex : entrées de lore découvertes au fil des runs.
  • PNJ à mémoire : se souviennent du joueur entre les runs. Faveur/hostilité persiste.
  • Réputation (3 états par faction) : Hostile / Neutre / Favorable. Affecte cartes, difficulté, ton.

Save/Resume (R108)

Point atomique : début de beat (après advance_beat, dé tiré). Les transients (combo en cours, UI, stream LLM) ne sont jamais persistés. Un run terminé n’a pas de save zombie.

Calcul de degré
couverts = tags_requis ∩ tags_joués
si couverts == requis + extra → Éclatante
si couverts == requis          → Réussite

Exemple : Partiel → Intégrité passe de 7 à 5.

corruption_delta = somme(carte.corruption pour chaque carte du combo)
si degré == Partiel: corruption_delta += 1
Exemple : Combo de 2 cartes (coût 0 + coût 1) + Partiel → +2 Corruption.

Intensité glitch

Effets (désaturation, aberration, tremblement) ∝ intensite
